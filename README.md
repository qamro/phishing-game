# phishing-game


**A simple 2D fishing game developed in Python using Pygame. Features randomly generated fish, interactive fishing mechanics, real-time movement, and a scoring system. A beginner-friendly project exploring game development fundamentals, event handling, and game loops in Python.**

# Running

To run the game just:

**Clone the repo** 

then:

**execute these two commands(this for activate the virtual environment and run the game):**
- source venv/venv/bin/activate                                           
- python main.py
